# Planer

Локальный планер дня в виде веб-приложения: чек-лист задач с подзадачами, голосовой ввод через
локальный Whisper и сравнение **плана** с тем, что **реально сделано**.

## Возможности

- **Чек-лист на день** с навигацией по датам (←/→, календарь, «Сегодня»).
- **Подзадачи** любой вложенности. Когда все подзадачи выполнены — родитель отмечается сам;
  отметка родителя закрывает его открытые подзадачи.
- **План / Факт.** Составляете список → жмёте «Зафиксировать план». Всё, что добавлено после,
  помечается как «вне плана». Вкладка «План / Факт» показывает две колонки: что планировалось
  (со статусами) и что реально сделано (включая внеплановое), с оценками и затраченным временем,
  плюс поле «Итоги дня».
- **Оценка и учёт времени**: «Отчёт 1.5ч» или «Созвон 30м» в поле ввода сразу ставит оценку;
  кнопка ▶ у задачи запускает таймер (одновременно идёт один).
- **Голосовой ввод** (локально, faster-whisper). Надиктуйте:
  > «Написать отчёт на два часа. Подзадача собрать данные. Подзадача сделать графики.
  > Потом позвонить маме на полчаса»

  Получится задача «Написать отчёт» (2 ч) с двумя подзадачами и задача «Позвонить маме» (30 мин).
  Перед добавлением текст можно поправить — превью обновится. Тот же диалог работает и как
  ввод списка текстом.
- **Перенос** незавершённых задач (с открытыми подзадачами) на завтра.
- **История** за 14 дней: сколько было в плане, сколько сделано из плана и вне плана.
- Светлая/тёмная тема, горячие клавиши: `N` — новая задача, `V` — диктовка, `←`/`→` — дни,
  `T` — сегодня. Двойной клик — переименовать, перетаскивание — порядок.

### Как разбирается диктовка

| Говорите | Получается |
|---|---|
| точка / новая фраза, «потом», «затем», «дальше», «и ещё» | новая задача |
| «подзадача …» | подзадача к предыдущей задаче |
| «подзадачи: а, б, в» | несколько подзадач |
| «на 30 минут», «на час», «полчаса», «полтора часа», «2 часа» | оценка времени |

## Запуск

Нужны Python 3.10+ и Node.js 18+.

```bash
./run.sh            # соберёт фронтенд и поднимет http://localhost:8000
```

Голос: `run.sh` ставит `faster-whisper` из `backend/requirements-voice.txt`. При первой записи
модель скачается с HuggingFace (дальше работает офлайн). Настройки через переменные окружения:

| Переменная | По умолчанию | Что это |
|---|---|---|
| `PLANER_WHISPER_MODEL` | `small` | `tiny` / `base` / `small` / `medium` / `large-v3` / `turbo` |
| `PLANER_WHISPER_LANG` | `ru` | язык распознавания (пусто — автоопределение) |
| `PLANER_WHISPER_DEVICE` | `auto` | `cpu` / `cuda` |
| `PLANER_WHISPER_COMPUTE` | `int8` | `int8`, `float16` (GPU) … |
| `PLANER_DB` | `data/planer.db` | путь к базе SQLite |

Без faster-whisper всё остальное работает, кнопка микрофона просто открывает ввод текстом.

### Разработка

```bash
python3 -m venv .venv && .venv/bin/pip install -r backend/requirements-dev.txt
cd backend && ../.venv/bin/uvicorn planer.app:app --reload     # API на :8000
cd frontend && npm install && npm run dev                      # UI на :5173 (проксирует /api)
cd backend && ../.venv/bin/python -m pytest                    # тесты
```

## Устройство

- `backend/planer/app.py` — FastAPI: дни, задачи, фиксация плана, перенос, таймеры, история, голос.
- `backend/planer/dictation.py` — разбор надиктованного текста в задачи/подзадачи/оценки.
- `backend/planer/speech.py` — локальная транскрипция faster-whisper (модель грузится лениво).
- `backend/planer/db.py` — SQLite-схема.
- `frontend/` — React + TypeScript + Vite, без UI-библиотек. Все цвета, радиусы и тени —
  CSS-переменные в начале `frontend/src/styles.css`, так что стиль легко подменить под внешний
  UI-кит.
