# Изменения

Формат: каждая версия — раздел `## X.Y.Z`. Текст раздела показывается в окне обновления
и в описании релиза на GitHub.

## 0.4.0

- Просторный дизайн: больше воздуха между блоками и внутри карточек, задачи дня — на общей
  подложке с тонкими разделителями, строки выше, хват для перетаскивания — за краем списка.
- Вкладка «Дашборд» вместо «Истории»: выбор периода (7/30/90 дней, этот и прошлый месяц)
  и проекта, ключевые цифры со сравнением с прошлым периодом (выполнение плана, сделано задач,
  время по таймеру, точность оценок, серия дней, просроченные), график «Сделано по дням»
  с подсказками и видом-таблицей, тепловая карта активности, выполнение по дням недели,
  разбивка по проектам и тегам, самые продуктивные дни. Клик по дню открывает его.
- Проекты получают разные цвета (уже созданные перекрашиваются автоматически).
- Исправлено «10 ч 60 мин» в подписях времени.

## 0.3.0

- Проекты и теги. В строке ввода: «Отчёт @Работа #срочно», голосом: «…, проект Работа, тег срочно».
  Подзадачи по умолчанию попадают в проект родителя.
- Сроки (дедлайны) отдельно от дня, на который задача запланирована: «до пятницы», «к 25 октября»,
  «до конца месяца». На задаче — метка срока (жёлтая — скоро, красная — просрочено), а в начале
  дня — блок «Сроки» с задачами из других дней и кнопкой «Взять на этот день».
- Вкладка «Задачи»: фильтры по проекту, тегу, периоду и статусу, поиск по названию и сводка —
  например, «всё по проекту Работа за этот месяц».
- Свойства задачи (оценка, срок, проект, теги) — в меню «⋯ → Срок, проект, теги, оценка…»
  или по клику на метку задачи.
- Диктовка стала понятнее: подсказка «как говорить», а распознанный список можно править —
  переименовать, сделать подзадачей предыдущей, убрать лишнюю метку или задачу.
- Поиск по названию без учёта регистра для кириллицы.

## 0.2.0

- Обновление по кнопке: «Проверить обновления» в приложении скачивает новую версию с GitHub,
  делает копию базы, заменяет код и перезапускается (с откатом, если новая версия не стартовала).
- Выбор микрофона в окне диктовки, индикатор громкости, понятное сообщение, если запись пустая.
- Тихая запись усиливается, при пустом результате распознавание повторяется без фильтра пауз.
- Исправлена ошибка распознавания с PyAV 19.
- Лаунчер macOS сам выбирает свободный порт, если 8765 занят другой программой.
- Установщику больше не нужен Node.js, если интерфейс уже собран (архив релиза).

## 0.1.0

  приложение для macOS.
