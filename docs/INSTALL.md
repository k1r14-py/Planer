## Как установить

Скачайте файл для своего компьютера из списка ниже («Assets»):

| Компьютер | Файл |
|---|---|
| Mac с процессором Apple (M1, M2, M3, M4…) | `Planer-…-mac-arm64.dmg` |
| Mac с процессором Intel | `Planer-…-mac-x64.dmg` |
| Windows | `Planer-…-win-x64.exe` |

Не знаете, какой у вас Mac? Меню  → «Об этом Mac»: строка «Чип: Apple M…» — Apple, «Процессор: Intel» — Intel.

**Mac.** Откройте `.dmg` и перетащите Planer в папку «Программы». При первом запуске macOS скажет,
что не может проверить разработчика (приложение не подписано платным сертификатом Apple):
нажмите «Готово», откройте **Системные настройки → Конфиденциальность и безопасность**, внизу у строки
про Planer нажмите **«Всё равно открыть»** и подтвердите. Это нужно сделать один раз.

**Windows.** Запустите `.exe` — Planer установится для текущего пользователя (права администратора
не нужны). Если появится окно «Windows защитила ваш компьютер», нажмите **«Подробнее» → «Выполнить в любом случае»**.

**Дальше:** Planer живёт в строке меню (Mac) или в трее (Windows); горячая клавиша **⌥⇧Пробел** / **Alt+Shift+Space**
открывает диктовку из любой программы. Новые версии ставятся кнопкой с номером версии в правом верхнем углу.
При первом запуске Planer один раз скачает модель распознавания речи (~500 МБ).

`planer-v….zip` — архив для кнопки «Обновить» и ручной установки через Терминал; обычным пользователям не нужен.
